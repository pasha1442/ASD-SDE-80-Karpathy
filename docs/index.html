What it is

ASD-STE100 is a standard for clear technical English. Its second name is Simplified Technical English (STE). European airlines asked for it in 1979. Many mechanics read English as a second language. A mechanic who reads an instruction incorrectly can cause an accident.

ASD-STE100 prompting uses this standard for a new reader: you. AI models write long sentences with filler words. Andrej Karpathy found a simple correction. He tells the model to explain the topic in ASD-STE100. Models know the standard from their training data.

  1. 1979Airlines ask for a controlled English for manuals.
  2. 1986The first Simplified English guide is published.
  3. 2005The guide becomes ASD-STE100.
  4. 2013The standard becomes free to download.
  5. 2025Issue 9 becomes an international standard.

Part 2: Dictionary
  • About 900 approved words.
  • Each approved word has one meaning and one part of speech.
  • About 1,200 words are not approved. Each has an approved alternative.
  • You can add technical nouns and technical verbs for your subject.

Why 80%, not 100%

Karpathy asks for "80% of the way to ASD-STE100". The full standard is very strict. Its dictionary has no words for most software ideas. If you ask for the full standard, the model can remove a technical term and the fact that goes with it.

Facts lost when Claude explained code, compared with no style instruction
Prompt: "Simple Technical English"
8.5%
Prompt: "ASD-STE100" (full)
46.8%

A second test used plain prose with few technical terms. In that test the full standard lost no facts. The conclusion: the risk comes from technical terms.

An example of a lost fact

Normal answer

The function debounces the resize handler by 200 ms.

Too strict

The function waits before it does the work again.

This example was written for this page. The strict version lost the term "debounce" and the value "200 ms".

CAUTION

STE makes sentences shorter. It does not make answers shorter. In the second test, the answers had the same total length.

Always add this line: "Keep product names, code names and technical terms as they are."

When to use it

STE helps with text that you use for reference. It hurts text that must sound like a person. Answer the questions to get a recommendation.

STE helpsSTE hurts
Long explanations become easy to scan.Introductions and stories read like a parts list.
One word keeps one meaning.The full standard can remove technical terms.
One line in a prompt is sufficient.The answer does not become shorter.
Error messages and instructions become clear.Your personal voice becomes flat.

Limits of the technique

A prompt is a request. It is not a guarantee. The model can write text that looks like STE and still breaks the rules.

Two errors in a popular cheat sheet

A one-page summary of the standard was shared with Karpathy's post. A review found errors in it. The page looked clear and correct, and it was still incorrect in these rows.

The cheat sheet saysThe standard says
Do not write "approximately". Write "about"."Approximately" is approved. "About" is approved only with the meaning "concerned with".
"Test" is an approved verb."Test" is approved only as a noun: "Do a test of the circuit."
CAUTION

A clear answer can be incorrect. Before you use an answer, check one important fact against the original source.
